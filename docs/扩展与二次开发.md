# 扩展与二次开发

这个项目的每一层都是可替换的。下面按「你想改什么」组织，每条都给出要动的文件和最小改动量。

---

## 1. 换掉答案生成的模型 / 端点

**改配置就行，不用改代码。** `config/settings.json`：

```json
{
  "base_url": "http://127.0.0.1:8080/v1",
  "llm_model": "qwen2.5-14b-instruct",
  "api_key_file": "config/api_key.txt"
}
```

任何 OpenAI 兼容端点都能接（llama.cpp server、vLLM、Ollama 的 `/v1`、各家云厂商）。
注意两点：

1. **不要用思考型模型**：实测首字 6690ms，面试场景不可用。要本地跑就选 7B~14B 的非思考指令模型；
2. 本地模型的首字延迟通常比云端高，`TP_TIMEOUT`（默认 8 秒）和 `TP_FIRST_WARN`（默认 5 秒）可能要调大。

## 2. 换掉 ASR

接口在 `server/asr_engine.py` 的 `SenseVoiceASR` 类，只要满足「给一段 float32 音频 → 返回文本」就能换：

```python
class MyASR:
    def __init__(self, model_dir): ...
    def warmup(self): ...              # 启动预热，别让第一次识别卡 20 秒
    def transcribe(self, audio): ...   # audio: numpy float32, 16kHz 单声道
```

然后在 `server/main.py` 里把 `asr = SenseVoiceASR(MODEL_DIR)` 换成你的类。
采集侧（`LoopbackCapture`）与 VAD（`EnergyVAD`）都不用动。

> 换模型时注意：模型路径必须是不含中文的绝对路径 —— 这不是本项目的要求，是 sentencepiece 的 C++ 层。

## 3. 换检索（加向量检索 / 换分词器）

检索在 `server/knowledge.py`：`load_docs()` → `chunk()` → `BM25`（词级）→ `search()`。
语料加载走 `settings.corpus_globs()`，所以**不加代码也能换语料范围**。

要加一路向量召回：在 `BM25.search()` 之外再写一个 `VectorSearch.search()`，用 RRF 融合两路排名。
文件里已经有一个现成的负面教材可参考 —— 字级 bigram 通道，代码保留、默认关闭：

```python
RRF_W_BIGRAM = 0.0    # 实测 39 条真实提问：词级 hit@1 69.2% / hit@3 84.6%，
                      # 加 bigram 一路后全面下降，所以默认关。要试就把权重调到 0.2~0.5 自己看数
```

评测脚本：`python tools/regress.py`、`python tools/test_hybrid.py`（需要你自己的测试集）。

## 4. 接自己的「深答线」

深答线是一个可选的外部命令：给它一个问题，它带工具回答（默认实现是调一个本地 agent CLI）。
在 `config/settings.json` 里配三项即可：

```json
{
  "dsh_node": "C:\\path\\to\\node.exe",
  "dsh_bin": "C:\\path\\to\\agent-cli.js",
  "dsh_home": "C:\\path\\to\\agent-home"
}
```

三项留空 = 深答功能自动关闭（浮窗上那个按钮点了会提示未配置）。
模板在 `server/deep.py` 的 `TASK_TMPL`：想要什么样的输出结构，改那段提示词就行。

## 5. 改浮窗（快捷键 / 配色 / 布局）

`ui/app.py` 顶部就是配置区：

| 想改什么 | 在哪里 |
|---|---|
| 热键 | `HOTKEYS` 表（每项：ID / 虚拟键码 / 名字 / 动作 / 说明）。被别的软件占用时会自动换一个键并在启动日志里写明 |
| 核心句长度阈值 | `MAX_CORE_CHARS`（默认 40，超过就给黄色「别照念」提示） |
| 字号与配色 | `_set_core()` 与 `PAINT` 相关的样式表 |
| 窗口尺寸/初始位置 | `Teleprompter.__init__` 里的 resize / move |

改完不用重启后端，直接重启浮窗即可（`python tools/launch.py` 是幂等的，不会起第二个后端）。

## 6. 加一个新的输入源

现在只抓系统回环（`LoopbackCapture`，soundcard 的 WASAPI loopback）。
如果要用麦克风阵列或网络流，实现一个同样接口的类即可：

```python
class MyCapture:
    def frames(self): ...        # 持续 yield 20ms 的 16000Hz 单声道 float32 帧
    def device_name(self): ...   # 显示在浮窗状态栏上
```

`server/main.py` 的采集循环里有自愈逻辑（插拔耳机、切默认设备后自动重连），换采集源时这段要一起适配。

## 7. 打包分发

项目当前以「源码 + venv」方式运行（最简单、也最容易调试）。
如果要给不装 Python 的人用，推荐顺序：

1. `pyinstaller --noconsole` 打包 `tools/launch.py` + `ui/app.py`（注意把 `models/` 排除在包外，让用户自己下）；
2. 用 Inno Setup 做安装包，安装时跑 `tools/download_model.py`；
3. 首次启动做预热（21.7 秒），别让用户以为卡死了。

## 8. 提交前

```powershell
python -m compileall -q server ui tools
ruff check .
pytest -q
```

改动了延迟或准确率的，请在 PR 描述里贴**改动前后的实测数字**和跑测命令 —— 见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
