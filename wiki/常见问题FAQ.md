# EarShot（顺风耳）· 常见问题 FAQ

> 每条都尽量给实测结论或明确说「没测过」。有数字的地方都是本机实测值。
> 数据流与合规章节见 `docs/隐私与安全.md`。

---

## 隐私与联网

### 1. 要联网吗？

**要，但只有生成答案这一步要。**

- 不需要网：回环采集、VAD、语音识别、检索、浮窗渲染——全在本机。
- 需要网：把「问题 + 检索到的材料片段」发给 DeepSeek 生成答案（默认 `https://api.deepseek.com`）。
- 断网时的降级：题库里有现成答案会自动铺成「【离线题库】…」那一行；没有命中就只剩「自己讲」。所以断网不会崩，但会退化成「没有现场生成」。

### 2. 会泄露吗？到底把什么发出去了？

**音频一帧都没有出本机。** 出本机的只有**文本**：

1. 识别出来的问题文本（面试官原话的转写）；
2. 本地检索命中的材料片段（top-k）；
3. `config/company.md` 的全文（每题都带）；
4. 上文 1~2 句（上一问、上一答，用来接「那这个呢」这类省略式追问）。

逐字段、逐文件的说明见 `docs/隐私与安全.md`。要点是：**发出去的是你自己材料里的片段**，所以真正的隐私决策是「哪些材料该放进 `knowledge/`」，而不是「这个工具会不会偷偷录音上传」——它不会。

### 3. 能完全离线用吗？

**默认不能。** 语音识别这条路本来就是离线的（SenseVoiceSmall ONNX int8，本地、零 API 调用），但**答案生成**默认在 DeepSeek 上。断网时只剩「本地题库兜底」这一条降级路径。

**有条件的例外**：`base_url` 是可配置的（任何 OpenAI 兼容端点），所以你可以在本机跑一个 llama.cpp / vLLM 之类并把 `base_url` 指过去，那就是全本地链路。**但这条组合本项目没验证过（待补）**：提示词、流式解析、超时与看门狗都是照 DeepSeek 的接口行为调的，换端点要自己测首字延迟与格式合规性。

顺带一句：DeepSeek **没有**语音识别 API，所以「换一家云 ASR」和「换掉 DeepSeek」是两件独立的事——本项目选的是本地 ASR + 云端 LLM。

### 4. 密钥放在哪？会不会被我提交到 GitHub？

- 默认放在 `config/api_key.txt`（明文文件，一行）。`config/api_key.txt` 与 `config/settings.json` 都在 `.gitignore` 里。
- 也可以用环境变量 `TP_API_KEY`（优先级高于配置文件），这样密钥可以完全不落盘。
- 别做的事：把整个工作区同步到公共网盘 / 共享盘；把 `logs/session_*.jsonl` 或 `config/terms_review.md` 直接截图发群里——**这两个文件里有公司名、项目数字和技术栈**。
- 泄漏了就去 DeepSeek 控制台吊销重发。

## 能力与边界

### 5. 支持什么语言？

模型（SenseVoiceSmall）的词表覆盖**中文 / 英文 / 日语 / 韩语 / 粤语**；但**本项目只在中文技术面试上实测过**（实测 3/3 句 100% 正确，含「十二 / 八百 / 二百六十」这类数字全对）。

英文及其它语言：识别层面可能可用，但检索词典（jieba + 领域词典）、疑问判定规则、提示词与话术全部是按中文面试调出来的，**未做验证（待补）**。

### 6. 能用来看讲座、听课、做会议纪要吗？

**技术上能跑，但别指望它好用，它不为这个场景设计。**

1. 它**只抓系统回环**（扬声器/耳机要播放的声音），**不抓麦克风**——所以线下会议、你自己说话，它听不见。这是刻意的设计（省掉声纹分离）。
2. **没有说话人分离**：多人混轨时分不清是谁在说。
3. 输出的是「面试口径」的答案（先给判断、再给落点、结合对方公司），不是纪要口径（谁说了什么、结论、待办）。

做字幕/纪要请用专门工具；这个工具的答案是为「抬头一秒念出来」优化的。

### 7. 要花钱吗？

- 本地部分 **0 成本、0 网络**：采集、识别、检索、浮窗。
- 花钱的只有 DeepSeek 调用，按官方现行价目计费（单价会变，这里不写具体数字）。计费口径：**每个真提问一次调用**，被「非提问过滤」拦掉的句子不调用——实测真实一面 50 段面试官发言里有 6 段是调设备/自言自语，拦掉等于省约 12% 的调用。
- 深答线（`dsh_*` 配置）如果开启，每次是一个完整的 harness 会话，更贵；**默认关闭**。

### 8. 知识库要多大？

本机实测：8 类材料 → **338 个切块**，索引构建 **1.0 秒**，单次检索 **0~1 ms**。所以几十 KB 到几 MB 都没压力，瓶颈不在大小。

真正决定质量的是**密度**：把「能讲出判断、数字、取舍的深度报告」放进去，比堆十份简历有用。另外，材料如果本身是语音转写稿，**先把专有名词错别字修掉**（lara←LoRA、rog←ROS、rug←RAG），否则检索和「没准备过」判定会跟着一起歪。

### 9. 能换语音识别模型吗？

配置里只有一个口子 `model_dir`。理论上换一个同接口的本地模型目录可行，但**没验证过（待补）**：`server/asr_engine.py` 假设的是 SenseVoiceSmall 的输出与词表结构，换模型要自己改代码并重跑 `tools/preflight.py`。

### 10. 能换大模型吗？

能：`base_url` + `llm_model`（任何 OpenAI 兼容端点都可以填 `base_url`，见 `docs/配置手册.md`）。但实测只有两个可用名字：

| 模型 | 实测 | 结论 |
|---|---|---|
| `deepseek-flash` | 首字中位 546 ms（官方名；别名 `deepseek-v4-flash` 是 694 ms） | **用这个** |
| `deepseek-v4-pro` | 6690 ms（思考模型，关不掉思考） | 不可用 |

### 11. 支持 macOS / Linux 吗？

**不支持，当前是 Windows 专用的。** 依赖的 Windows API 有四个，缺一个就跑不起来：

| 用途 | 依赖的 Windows API | macOS/Linux 的状况 |
|---|---|---|
| 抓面试官声音 | WASAPI 回环（系统渲染流） | macOS 没有等价回环接口，要装 BlackHole 这类虚拟声卡；Linux 要 PulseAudio monitor |
| 全局热键（不依赖焦点） | `RegisterHotKey` + `WM_HOTKEY` | 可换成各平台的热键库，但代码要改 |
| 防共享（截图里不可见） | `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` | **没有等价物**——macOS 上这个能力做不了 |
| 置顶压过全屏窗口 | `SetWindowPos(HWND_TOPMOST)` 每 2 秒保活 | 各平台有各自做法，但行为不同 |

### 12. 能同时开两场面试吗？

**不能，也不应该。** 一台机器只有一路回环、一个默认播放设备。

- 第二个后端会被**拒绝启动**（它会检测已在跑的后端进程或已应答的端口）：两个后端抢同一路音频，同一句话会识别两遍、出两份答案，还会互相覆盖端口文件——实测发生过。
- 浮窗也有 PID 去重（`.ui_pid`），开不出第二个窗口（两份一样的画面 + 互相抢焦点）。

### 13. 答案会不会很假？

有可复核的实测口径（真实一面 44 条提问全量回放）：

- 答案质量 LLM 判分 **4.09~4.14 / 5**；「不能照念」的答案从 13/44 降到 **0~5/44**；**数字幻觉 0**（唯一一次报警是误报）。
- 提示词里写死了「【核心】那句是要抬头直接念的，不要写『我判断面试官想问的是…』这种描述性开场」——这条把元描述式核心句从 **37% 压到 0%**。
- 列举型问题会先给清单（「还做过哪些业务」这类原来最容易答成「怎么做的」）；短确认题会压到 60 字内。

但「假不假」最终取决于材料是不是你自己的话。材料是别人的模板，念出来就是 AI 腔——这个工具改不了。

### 14. 为什么第一题比后面的慢？

实测：同一句话，**第一题墙钟 4000 ms、第二题 951 ms**，差的 3 秒全在 DNS + TLS 握手。修复办法是启动阶段先打一发 1-token 预热：**首题 4000 ms → 1264 ms**。

所以启动之后别急着问第一句，等浮窗显示就绪。另外首字延迟本身有网络抖动（实测 281~831 ms），偶发慢一次不用紧张。

## 用法与故障

### 15. 为什么模型必须放在纯 ASCII 路径？

因为 **sentencepiece 的 C++ 层处理中文路径会报 `NOT_FOUND: No such file or directory`，而 Python 侧 `os.path.exists()` 对同一个路径返回 True**——错误看起来像「文件丢了」，其实是路径里的中文。

启动时 `ensure_ascii(path)` 会直接抛错并给出改法（改 `model_dir` 或换目录），不会让你对着「文件明明在」debug 一小时。只有 **ASR 模型目录**有这个限制；仓库本身放中文路径是没问题的。

### 16. 为什么第一次启动这么慢？

三笔账：**首次识别含 numba JIT 编译要 21.7 秒**（预热后约 100 ms）；模型加载 **4.0 s + 预热 3.8 s**；再加建索引约 1.0 s 与答题链路预热，启动总开销约 8 秒以上。

启动器靠 `/healthz` 的 `ready=true` 判断「真的能用」（HTTP 能应答 ≠ 模型加载完了）——不加这个门，浮窗会在后端还在预热时就起来，实测让首题墙钟从 1.3 秒涨到 3.8 秒。

### 17. 为什么我的深答键不是 Ctrl+Shift+D？

因为**全局热键首选键被别的软件占用时，程序会自动换成备用组合**（全局热键一旦退化成「窗口内快捷键」，面试时浮窗没有焦点就等于没有）。实际生效的键写在**浮窗底部提示行**。

本机实测 `Ctrl+Shift+D` 被占（`RegisterHotKey` 返回 `winerr=1409`），深答实际落在 **`Ctrl+Shift+J`**。**永远以浮窗底部提示行为准，别背热键表。**

### 18. 为什么「追问预案」不是 AI 现场生成的？

因为它原来是：DSH 深答线子进程。实测**地板 9~13 秒、冷启动 31.6 秒**——面试里没人等得起。现在改成「题库近邻」：面试官的下一个问题很可能来自题库里同一章节的问法，本地算，**0 延迟、0 花费**。

深答线仍然可选（`dsh_node` / `dsh_bin` / `dsh_home` 配齐即开启），但**默认关闭**，只在你有 30 秒空档时才值得按。

### 19. 端口 8765 被占了怎么办？

不用管。后端从 8765 起自动顺延到 8766~8769，把实际端口写进 `.runtime_port`，浮窗每次重连都重读它（旧版写死端口，一冲突就永远显示「未连接」）。

如果 8765 是被**别的**程序占用，`tools/preflight.py` 第 8 项会 FAIL 并告诉你占它的是谁。

### 20. 转写错了 / 面试官说的词我不认识，怎么办？

三件事，按顺序：

1. **面试官的话也是 ASR 出来的**，专名可能是写坏的（实测 lara←LoRA、rog←ROS、rug←RAG、lmm←LLM）。先反问对齐：「你说的 X 是指……吗？」——万一听岔了，面试官会当场纠正，比你照着错词答安全。
2. 材料外名词会自动切成「坦诚」策略（琥珀色标签）：照念第一句直接承认没做过，然后按理解推、说能迁移的经验。**这里绝对不能自由发挥**——编「我用过」被追两层就穿帮，性质从「不会」变成「不诚实」。
3. 整句都听错了 → `Ctrl+Shift+P` 暂停，用展开区的手动提问行补一句（手动提问不走「非提问过滤」）。

### 21. 会不会被面试平台检测到？

**老实说：这个工具没有做任何对抗性伪装。** 它就是一个普通 Python 后端进程 + 一个 Qt 浮窗。

- `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` 能做的只有一件事：**让这个窗口不进屏幕截取/录屏**（实测系统截屏里窗口完全消失）。
- 它**防不住**：手机或相机拍屏、采集卡、部分第三方采集链路上的「共享整个桌面」、以及对你本人的摄像头拍摄。
- 多数公司的面试协议明确禁止 AI 代答或外部辅助，部分平台会检测异常进程、要求开录屏或共享整个桌面。**这是你自己的判断，不是工具的判断**（详见 `docs/隐私与安全.md` 的伦理与合规一节）。

### 22. 不装 DeepSeek 密钥能跑吗？

跑不了快答线。`tools/preflight.py` 第 7 项会直接 FAIL（密钥文件不存在 / 内容为空 / 调不通 / 没首字 / 一个 content 增量都没有），并说明是哪一种。

没有密钥时你只剩本地题库兜底：命中就有「【离线题库】…」，没命中就什么都没有。

### 23. 能不能顺便转写我自己的声音（复盘我的回答）？

**当前不能。** 只抓系统回环，麦克风那条线完全不碰——这是刻意的：省掉声纹分离这一步，也就不存在「把两个人的声音混在一起」的问题。

要复盘自己的回答，用会议软件导出的录音稿：`tools/extract_docx.py` 转文本 → 放进 `knowledge/` → 按 `tests/real_questions.json` 的格式标注意图 → `python tools/regress.py --e2e`。

### 24. 我想改启动脚本里的中文提示，结果 cmd 报「找不到文件」？

`.bat` / `.ps1` 必须**纯 ASCII + CRLF 换行**：cmd.exe 按 GBK 读批处理，写 UTF-8 中文会乱码并报「找不到文件」（实测过）。

所以启动器 `.bat` 只做壳子，所有逻辑都在 `tools/launch.py` 里。要改行为就改 Python，别往批处理里写中文。

### 25. 换个面试官 / 换一场面试，要重跑什么？

至少这三样（都是几十秒到一分钟的事）：

1. `python tools/regress.py` —— 9 项回归门禁。**路由分类的 100% 是照上一场数据调出来的拟合上限**，换人必降，必须重测。
2. `python tools/build_terms.py` + 手标 `known_terms.md` / `never_used.md` —— 「没准备过」判定依赖这份人工白名单。
3. `python tools/preflight.py --fast` —— 换环境（换电脑、插拔耳机、装了新软件抢热键）之后必跑。

材料更新过还要 `python tools/build_bank.py` 重建题库（约 30 秒 / 854 条），否则会一直用旧问法答新问题。
