# 配置手册

EarShot 的配置分三层，优先级从高到低：

1. **环境变量**（临时覆盖、脚本里用）
2. **`config/settings.json`**（本机长期设置，已 gitignore）
3. **代码默认值**（`server/settings.py`）

另外还有三份「你自己的信息」放在 `config/` 下的 Markdown 里（不是 JSON 配置，是给模型的上下文）。

---

## 一、`config/settings.json`

模板见 `config/settings.example.json`，复制一份改名即可：

```powershell
Copy-Item config\settings.example.json config\settings.json
```

| 键 | 默认值 | 说明 |
|---|---|---|
| `model_dir` | `<仓库>/models/SenseVoiceSmall-onnx` | ASR 模型目录。**必须是不含中文的绝对路径**，否则 sentencepiece 会在 C++ 层报 `NOT_FOUND` |
| `api_key_file` | `<仓库>/config/api_key.txt` | DeepSeek 密钥文件（文件内容就是密钥本身，首尾空白会被去掉） |
| `base_url` | `https://api.deepseek.com` | 任何 OpenAI 兼容端点都可以填这里（想全本地就指向 llama.cpp / vLLM 的 `/v1`） |
| `llm_model` | `deepseek-flash` | 答案生成模型。**不要用思考型模型**：实测首字 6690ms，面试场景不可用 |
| `corpus_globs` | `["<仓库>/knowledge/**/*.md", "<仓库>/knowledge/**/*.txt"]` | 知识库语料的 glob 列表，可以指向任意目录 |
| `ports` | `[8765, 8766, 8767, 8768, 8769]` | 后端监听端口，被占自动顺延，实际端口写进 `.runtime_port` 供浮窗读取 |
| `dsh_node` / `dsh_bin` / `dsh_home` | 空 | 深答线（可选）：一个能带工具回答的外部 agent 命令。三项都留空则深答功能自动关闭 |
| `vad_end_ms` | `600` | **判停**：静音超过这么多毫秒就认为一句话说完。调到 350~400 实测能让答案早约 200ms 出现，代价是语速慢、爱停顿的人会被切成两句（检索质量下降） |
| `core_max_chars` | `40` | 核心句超过这个字数就标黄 + 缩字号（一秒念不完，实测这类念法合规率只有 79%）。20~60 之间调 |
| `core_font_px` | `20` | 核心大字基准字号（像素）。屏幕小调小、视力吃紧调大 |

### 手感参数怎么调

上面最后三个是**手感参数**，都有安全默认值，不写就是现在的手感。改完**重启后端 + 浮窗**生效（配置在启动时读一次）。三个的取舍：

| 想要的效果 | 改哪个 | 代价 |
|---|---|---|
| 答案出得更快 | `vad_end_ms` 600 → **350~400** | 停顿多的人会被切句，一句变两句 |
| 屏幕上多放几个字 | `core_font_px` 20 → **16~18** | 瞟一眼的辨认速度变慢 |
| 别再让我念长句 | `core_max_chars` 40 → **25~30** | 信息量少的题答案会更短 |

> 这三个参数**浮窗和后端读的是同一份** `config/settings.json`（`ui/app.py` 直接 import `server/settings.py`），
> 不会出现「浮窗一套默认值、后端另一套」的错位。

## 二、环境变量

| 变量 | 等价于 |
|---|---|
| `TP_MODEL_DIR` | `model_dir` |
| `TP_KEY_FILE` | `api_key_file` |
| `TP_API_KEY` | 直接给密钥（优先级最高，适合 CI / 临时换 key） |
| `TP_BASE_URL` | `base_url` |
| `TP_LLM_MODEL` | `llm_model` |
| `TP_CORPUS_GLOBS` | `corpus_globs`（多个用分号 `;` 分隔） |
| `TP_PORTS` | `ports`（逗号分隔） |
| `TP_DSH_NODE` / `TP_DSH_BIN` / `TP_DSH_HOME` | 深答线三项 |
| `TP_TIMEOUT` | 快答线超时秒数，默认 `8`（面试里没人等得起更长） |
| `TP_RETRIES` | 快答线重试次数，默认 `1`（失败就走题库兜底） |
| `TP_FIRST_WARN` | 首字看门狗阈值秒数，默认 `5`：超过就提示「这题自己先讲」 |
| `TP_SHOT_AFTER` | 浮窗启动 N 秒后自动截图（自检用） |
| `TP_NO_WS` | 自检用：不连后端，只渲染假数据 |

示例：

```powershell
$env:TP_MODEL_DIR = "D:\asr\SenseVoiceSmall-onnx"
$env:TP_TIMEOUT = "6"
python tools\launch.py
```

## 三、三份「你自己的信息」（config/*.md）

这三份不是配置项，而是**每次提问都会带进模型上下文**的材料。

| 文件 | 什么时候用 | 写法 |
|---|---|---|
| `config/company.md` | 每题都带 | 公司业务、JD 关键要求、技术栈线索、面试轮次、你想强调的匹配点。**填得越具体，设计题越贴业务** |
| `config/known_terms.md` | 判断「这个词我到底会不会」 | 一行一个（空格/逗号/顿号分隔）。你会的技术都写进来，提词器就不会让你对它们说「没接触过」 |
| `config/never_used.md` | 同上，反向 | 材料里被顺带提到、但你其实没做过的东西。命中就走「坦诚」话术，不管材料里写了多少 |

> 词表怎么生成：`python tools/build_terms.py` 会把材料里的技术名词列成表格，你过一遍，
> 会的抄进 `known_terms.md`，没做过的抄进 `never_used.md`。跑一次两分钟，但这一场的「我不会」就全都锚死了。

## 四、知识库（`knowledge/`）

- 默认读取 `knowledge/**/*.md` 与 `knowledge/**/*.txt`，可在 `corpus_globs` 里改；
- 内容会被切成 300~700 字的块，**文件名会加权参与检索打分**，所以文件名取清楚些（如 `项目A_推荐系统.md`）；
- 数字、指标写进句子里，别只放表格；小标题写成人话，更容易和面试官的口语提问对上；
- 这个目录默认被 `.gitignore` 忽略，你的简历与项目材料不会被推到 GitHub。

## 五、运行期文件

| 路径 | 作用 |
|---|---|
| `.runtime_port` | 后端实际监听的端口（浮窗每次重连都重新读一遍） |
| `.ui_pid` | 浮窗 PID，启动器靠它判断「是不是已经开了一个」 |
| `logs/launch.log` | 启动器日志（谁先起、健康检查结果） |
| `logs/backend_console.log` | 后端标准输出 |
| `logs/backend_error.log` | 线程里抛出的异常（不会打到控制台的那些） |
| `logs/session_*.jsonl` | 每场会话的完整记录：转写、答案、耗时 —— 赛后复盘与做测试集都从这里来 |
| `.tmp/` | 保留最近 20 段录音（用于排查），会自动清理 |
